# OMOP → SPARQL using Ontop and DuckDB

This repository demonstrates how to expose OMOP CDM data stored as
Parquet files as a SPARQL endpoint using Ontop and DuckDB without RDF
materialization.

Two supported modes:

1.  Ontop CLI (standalone endpoint)
2.  GraphDB Desktop with embedded Ontop
